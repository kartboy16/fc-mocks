How A works

  • Columns sits next to Filters and looks like it (same small outlined button). A badge shows how many extra columns are on, e.g. "+3".
  • Ticking or unticking saves immediately. Nothing else on the page changes (filters, sort, page).
  • Email can't be turned off. Every other column, including today's defaults, can.
  • New columns are added on the right in the order you tick them. To change the order, untick and re-tick (or pick B).
  • "Reset to default" puts back exactly today's columns.

Why recommended

  • One click to open, one click per field. It's the least to learn and matches the Filters menu advisors already use.
  • Smallest build: no drag-and-drop, no header menus.
  • Reorder can be added later (B's drawer) without changing what's saved.

Same in every direction

  • Default view is unchanged: Email, Name, Status, Engagement, Lists, Tags. (Engagement is in today's table, so it stays on by default.)
  • The choice is saved for the advisor's account, so it follows them across sessions and devices. An admin acting as the advisor sees and changes the same choice.
  • Fields imported from Mailchimp are labelled "From Mailchimp". Fields from a CSV import are labelled "From CSV".
  • The contact page always shows every field, whatever columns are on.
  • Export still includes every field (proposed default). See the build contract.
  • Phones show the basic card view and no Columns control.
