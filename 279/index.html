Allow 2+ email footers and choose which one for newsletters

Alana Read wants to save two or more email footers and pick which one per campaign. Today: one global footer under Headers & Footers (Simple/Advanced). Compose shows Footer preview + Edit only — no picker. Audience: advisors 50s–60s and less tech-savvy assistants — plain words, big controls.

Recommend · Direction A — Named footers library + picker
Open Direction A (recommended) Manage footers · Edit · Newsletter picker + preview · Legacy migrate · Delete confirm

Provisional build contract · Markdown

Problem: Firms often need more than one email footer (e.g. “Standard” vs “Compliance-heavy”) and must choose which applies to a campaign. Today Headers & Footers has one global footer; Create New Campaign only shows Footer preview + Edit. We need a named list in that same place and a picker above Footer preview — without redesigning the whole campaign composer. CASL mailing address / unsubscribe stay separate under Mailing & compliance.
Acceptance criteria (cover in mocks)
  • AC-1: Create/keep ≥2 distinct footers (name/label + HTML/content as today).
  • AC-2: Legacy single footer → migrate as default named footer; no breakage.
  • AC-3: On compose/schedule email newsletter, choose which saved footer (clear default if none picked).
  • AC-4: Chosen footer in preview + send (note approval path if shown).
  • AC-5: Edit/rename/delete non-default without breaking past campaigns — recommend snapshot-at-send.
Out of scope
  • Per-recipient dynamic footers
  • Redesigning the whole email composer
  • Social or website footers
Open product questions — do not invent locked answers Resolve before agent-ready
  1. Firm-shared footers vs per-advisor footers?
  2. Who can delete Default? Must always have ≥1 footer?
  3. Snapshot-at-send vs live-reference for past campaigns? Recommend snapshot.
  4. Does the approval queue re-check the footer if it is edited after submit?
Track: Basic enhancement → staging after mock approved. Designer-first. Do not mark agent-ready until Alex/Angelina pick a direction and attach this Pages URL to the issue.
Scout-aligned nav (live app): Settings & Branding → Mailing & compliance → Open Email Campaign settings → Email Marketing → Settings → Headers & Footers. Compose: Email Campaigns → Create New Campaign → Footer preview + Edit. Unsubscribe auto-added if absent; CASL address under Mailing & compliance.

Directions

RECOMMEND

A — Named footers library + picker

Headers & Footers becomes a named footers list (like email signatures). Create New Campaign gains a footer dropdown above existing Footer preview + Edit; Default marked. Best for firm governance + clear mental model.

 ALT

B — Footer templates inline on compose

Create/save footers from Create New Campaign (“Save as footer…”), plus a compact link back to Headers & Footers. Good for power users; weaker for firm-wide governance.

 ALT

C — Firm default + per-newsletter override

One Default always applied; compose only shows Override → pick another. Minimal UI change; weaker when Standard vs Compliance need equal weight.

Provisional build contract (recommend A)

Snapshot footer HTML at send/schedule (AC-5) so compliance PDF stays same HTML as sent. Migrate legacy single Headers & Footers footer → named “Standard” as Default. Firm vs advisor ownership left open. Full text: build-contract.html.
