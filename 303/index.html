Email Campaigns — Insert posts from Content Library

Advisors editing a campaign should browse/search Content Library posts they can access and insert selected post (or email-ready content) into the campaign body — not copy/paste by hand. Reporter: Angelina (#fc-bugs).

Recommend · Direction A — Modal picker from editor
Open Direction A (recommended) Campaign editor · Insert from library modal · search/filters · preview · insert into body

Provisional build contract · Markdown · Directions brief

Problem: Advisors building email campaigns need Content Library posts they already have access to — without leaving the campaign and copy/pasting. Today there is no in-flow browse/search/insert. Goal: pick a post (prefer Type: Email) and drop email-ready body into the campaign canvas/blocks.
Soft Dev hold · Idea / playground · not agent-ready. Designer-first mocks only. Do not wake Soft Dev. Do not mark agent-ready. CosB will ask Alex + Angelina in Slack which direction to lock.
Acceptance criteria (draft — cover in mocks)
  • From Email Campaigns, advisor can browse/search Content Library posts they have access to.
  • Advisor can insert a selected post (or its email-ready content) into the campaign being edited (body/blocks, not just subject).
  • Clear empty / loading / error states when no posts available or insert fails.
  • Behavior respects existing content access / approval rules (show only usable posts; optional Compliance Approved / Advisor-only badges).
Out of scope (this pass)
  • New MAP admin surfaces or Content Library authoring changes
  • Marking agent-ready / waking Soft Dev
  • content-library app code (mocks-only on fc-mocks)
Provisional product assumptions (call out in contract — not locked): Prefer filtering to Type: Email but allow other types with clear “Insert into email” using email-ready body when available. Access/approval badges are illustrative. Insert payload = email-ready HTML/block into campaign body.

Directions

RECOMMEND

A — Modal picker from editor

Stay in campaign edit. Toolbar “Insert from library” opens a centered modal: search + Topic/Type filters + cards → preview → Insert. Best focus + familiar picker pattern.

 ALT

B — Right drawer / side panel

Same editor; persistent right drawer so advisors can browse while seeing the canvas. Strong for compare-while-compose; slightly more chrome.

 ALT

C — Library-first step

From campaign list / “Add content”: choose From Content Library → full-page picker → return with content inserted. Closer to Library browse; leaves the editor mid-flow.

Provisional build contract (recommend A)

Entry: Campaign edit → Insert from library. Insert into body/blocks. List only posts the advisor can use. Empty/loading/error required. Full text: build-contract.html.
