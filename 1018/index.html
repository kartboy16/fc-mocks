#1018 Paste a contact list to add email subscribers

Problem: on Email Campaigns › Subscribers, contacts can only be added one at a time (or by CSV file), so pasting a list straight from a spreadsheet isn't possible.

These mocks add a Paste contacts entry point: one paste box, column auto-detect with manual mapping, a preview with counts and flags, a target list picker, and an import summary. All data is fictional (Jane Advisor, Sam Support, Your Firm Name, example.com). Every page has a Desktop / 390 toggle, or add &phone=1 to any link.

Risk: high (Email Campaigns UI). Server-side checks must repeat every client check, and unsubscribed or bounced addresses are never re-subscribed by a paste.

Recommended: B, the 3-step modal wizard. It matches the existing Import CSV, Import from Mailchimp and Add Contact dialogs, the steps force a look at the preview before anything is added, it becomes full screen on a phone, and the same Match and preview step can later serve the CSV import.

Directions

A. Inline panel on Subscribers

A panel opens above the subscriber table. Paste, then match columns, preview, pick a list and add, all in one panel. Fewest clicks, and you see the table update right under it. It gets long on a phone and crowds a busy page.

Empty · Pasted · Match columns · Preview · Skipped filter · Email only, no header · New list · Admin as advisor · Advisor picker · Over 1,000 rows · Importing · Summary · Error

B. 3-step modal wizard (recommended)

Steps: 1 Paste, 2 Match and preview, 3 Confirm (list, permission, add). Matches the other Subscribers dialogs and is full screen at 390.

Empty · Pasted · Match columns · Preview · Skipped filter · Email only, no header · New list · Admin as advisor · Advisor picker · Over 1,000 rows · Importing · Summary · Error

C. Full-page import with side-by-side preview

Its own page (Subscribers › Paste contacts), with the paste box and mapping on the left and a live preview on the right. Best for big pastes on a desktop, but it's a new route and it stacks into one long page on a phone.

Build contract · .md

Acceptance criteria coverage

  • AC-1 Paste contacts entry point and one paste box: Empty, Pasted
  • AC-2 Auto-detect, header row, manual mapping (Email required): Match columns, Email only, no header
  • AC-3 Preview with flags and counts, flagged rows skipped: Preview, Skipped filter
  • AC-4 Target list and admin acting as advisor with capped, paged picker: New list, Admin as advisor, Advisor picker
  • AC-5 Totals refresh and summary: Summary
  • AC-6 Unsubscribed and bounced/complained never silently re-subscribed: Preview, Skipped filter
  • AC-7 Row cap and server re-check: Over 1,000 rows, Importing, Error

Open questions

  1. Pick A, B or C.
  2. Row cap: 1,000 rows per paste is assumed. The issue suggests a few thousand. Is 1,000 right?
  3. Consent wording for skipped unsubscribed or bounced addresses is a placeholder. What should it say, and should there ever be a way to re-subscribe (assumed no)?
  4. An existing subscriber who isn't on the target list is treated as Ready and only gets the list added, without changing their name. OK?
  5. Inside a Log in as session the advisor is fixed, so no picker is shown (banner only). Is the advisor picker needed at all outside Log in as?
  6. The permission checkbox reuses the Add Contact wording. Keep it required for paste?
