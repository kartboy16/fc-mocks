Walkthrough (Alana's WWF case in Direction A)

  1. Open the advisor: Admin › Manage Advisors › Priya Desai › Media. This is Priya's own My Media library (the same one she sees, and the same one that holds her #400 infographics).
  2. Upload: "Upload for Priya" → choose Headshots → drop one or several files.
  3. Grab links: the success panel lists each file with its link and Copy. "Copy all new links" copies them one per line.
  4. Later: come back any time. Headshots sit at the top. "Copy all N headshot links" (on the Headshots tab) or "Copy all N links" on All. Tick "Include file names" to paste into a spreadsheet as two columns.
  5. Next advisor: switch advisors with the picker at the top. If firm batches are frequent, Direction B adds a single firm page.
Why A:
  • No new screen. It finishes the #260 library and adds a Copy link button, which is what Alana actually needs.
  • Works for advisors (single links) and staff (any advisor + Copy all) with one design.
  • Builds on what FC already does: staff can already upload a headshot for an advisor, and every file already has a public link. The missing pieces are a list and a Copy button.
