Walkthrough (recommended)

  1. Manage: Advisor opens Infographics (upload area). Sees a dropzone and a grid of their uploaded pieces (thumbnail, title, date). Empty state CTA: “Upload your first infographic.” Actions on each card: Preview, Rename, Replace, Delete (confirm), Set branding.
  2. After upload (or Set branding): Modal “Position the business card and footer.” Choose Logo Only (default) / Full Card / None, footer field order or None, paper Letter (default ~1054×1364) / A4 / Custom. Drag logo/card freely (5px snap); footer moves on Y only. Save → item lands in (or updates) the grid. Copy: branding saved with this infographic; defaults remembered for next time.
  3. Email Campaigns: While composing, “Insert infographic” opens the same library picker (search + grid). Selecting one drops a preview into the email body with a caption/alt line. “Manage library” links back to Manage.
  4. Social: When adding images, “Choose from infographics” opens the same picker. Selected piece fills the post image slot; remove / replace available.
