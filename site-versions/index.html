Site versions: go back to an earlier version of your website

Advisor-facing, in the advisor's FC account. If a release breaks their live site, a non-technical advisor can put an earlier version back in a few clicks. We save a backup first and check forms and pages. Not agent-ready. Soft Dev hold until Alex picks.

Recommend A: a versions table in Website › Versions, one row per release, with Current, View and Restore this version. It holds a long history, and every row is one click from a plain-words confirm step. About 7.5 to 10.5 days.
