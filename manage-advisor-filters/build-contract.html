One-liner

Show one row of summary chips, one per non-empty filter group / polarity. Clicking a summary chip opens a popover listing that group’s individual filters with remove (×) and search-within-group. Filters drawer stays as today.

Problem

50+ include/exclude chips (list source, suggest source, topics) wrap many rows and push the advisor table down. This changes active-filter presentation only, not the filter system.

Default strip

  • ~3–6 summary chips on one horizontal row; nowrap, with horizontal scroll if needed
  • Include list source(s) when present (solid blue)
  • Exclude list · N, Exclude suggest · N, Exclude topics · N (red outline)
  • Other live filter groups follow the same pattern when present
  • Clear all on the right; Filters toolbar badge remains the total active count

Popover

  • Anchored under / near the clicked summary chip; title is the group name
  • Search filters within that group
  • Each row keeps its existing production label prefix and has a single-filter × remove control
  • When a group is empty, close the popover and remove its summary chip
  • Close via ×, Escape, or click-outside
