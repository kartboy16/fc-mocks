#727 Advisor-started one-step WordPress connection

Recommend A, an inline card on Website → Settings with a stepper. The advisor types their website address, clicks Connect, approves once on their own WordPress approval page, watches four plain steps, and sees Connected. Errors appear on the same card with the next action. It is the smallest UI build and keeps the journey in one place. About 12–18.5 agent hours (cloud build + FC Tester + fix loop). High risk: the server-rule change needs a backup first.

Fixtures are Jane Advisor, Your Firm Name and example-advisor.ca. The WordPress approval screen is shown as context and is labelled as a WordPress screen. Compare with the earlier onboarding-based mocks, which stay available.
