Build contract · MAP Pick a post for me (#266)

Markdown: build-contract.md · Hub: index.html · Mock: Direction A

One-liner

On each Manage Advisor Posts advisor row, add Pick a post for me next to Suggest posts. One click ranks a library post using that advisor’s confirmed services + WP/MAP exclusions, skips categories from the last 3 posted, and prepends the result to that row’s Suggested scroller. Admin still Schedules or Skips — no auto-publish.

Recommended UI (Direction A)

  • Actions column: stack Suggest posts, then outline primary Pick a post for me, then Choose services / Load from WP as today.
  • Widen actions column slightly vs #254 (~140–150px) so labels wrap cleanly.
  • Posts cell chrome stays locked #254 Direction A (dense past + short suggest cards + Schedule/Skip).

Acceptance criteria

  • ☐ AC-1: New Pick a post for me control beside Suggest posts on each MAP advisor row.
  • ☐ AC-2: Ranking uses confirmed products/services (AdvisorConfigs.websiteServices). If none saved: follow #52 scan-once-if-empty or prompt Choose services — no second services store.
  • ☐ AC-3: Exclude WP history + existing MAP exclusion rules (recent suggestions, queue, hidden, etc. in post-suggestions.js).
  • ☐ AC-4: Result appears in that row’s Suggested scroller; Schedule/Skip unchanged; no auto-publish.
  • ☐ AC-5: Short “why this fits” (matched service) when available, consistent with AdminSuggestPostCard.
  • ☐ AC-6: Loading / empty / exhausted states clear and distinct from Suggest posts batch behavior.
  • ☐ AC-7: Do not pick a post in the same category as any of the last 3 posted. If every candidate collides → exhausted UI (e.g. “No posts outside your last 3 categories”), not a silent no-op.
