Website settings: "PHP on your server" option

This is a new way for posts to reach an advisor's own website. A small PHP folder on their web host shows their published FC posts at example.com/insights, inside the site's own header and footer, with full articles on their domain. It's built first for a static-site advisor. The data is generic. Not agent-ready. Soft Dev hold until Alex picks.

Today (reference): the Settings tab on staging, with two method cards (Article list and WordPress).

Recommend A, a third method card with an inline setup panel. It reuses today's card pattern, keeps setup and status on one screen, and costs the least. Setup is three steps (download, upload, check), plus Copy for the advisor ID and posts address, a Test connection button with a live status, a "which posts show up" note and collapsed developer details.

Directions

  • A. Method card + inline setup (recommended): about 2–2.5 UI days.
  • B. Setup wizard: a 4-step dialog (Your website, Download, Install, Check). After setup, the card shows "View status". About 3–3.5 UI days.
  • C. "Your website setup" status page: health at a glance, with setup in a side drawer. About 3.5–4.5 UI days.

Each direction has state buttons: Not set up, Downloaded, Waiting for first fetch, Connected and Error / stale. Copy, Download and Test connection all work, and Developer details opens. Every option also needs about 1.5–2 days of backend (fetch tracking, test, zip with ID), and depends on #638.
