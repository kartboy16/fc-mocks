Why A
  • Radios make the choice impossible to miss — every list is visible before Approve / Send.
  • One list per send keeps the audience clear (matches how advisors talk about General vs Corporate vs Group).
  • Single-list default is still visible (“Your only list · General (842 contacts)”). Multi-list blocks the primary button with “Choose a list to continue.”
  • Confirmation restates “Sending to Corporate (214 contacts)” and notes the list is saved on the campaign.
  • B is more compact but easier to skim past. C changes the product rule to multi-list sends — ask before shipping.
