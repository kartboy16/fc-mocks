Social share without website destination (WP not required)

The new advisor menu lets people post to social without WordPress connected — but share still assumes a website post URL. Social-only users can hit a missing or dead destination. Pick how we handle that.

Recommend · Direction C — Hybrid warn + post without link
Open Direction C (recommended) Warn before post · Connect website · Post without link · light banner when WP missing

Build contract · Markdown · Directions brief

Problem: Social share still assumes a website post URL. With Social connected and WordPress missing, advisors can try to share — and the destination link may be missing or broken. Silent dead links are the failure mode to avoid.
Soft Dev hold · Designer-first · not agent-ready. Do not wake Soft Dev. Do not mark agent-ready. Wait for Alex pick + CosB tips.
Why not hard-gate (A)? Recent product (#332 Setup help, new advisor menu) treats Social / Email / WordPress as independent connections. Blocking social until WP is connected fights that model. Social-native (B) is fine if Alex wants zero friction — C keeps independence but prevents silent dead links.
Acceptance sketch (product) — recommend C
  • Social share/schedule allowed when WP is missing
  • Before post/schedule: short warn dialog — “No website connected — posts won’t include a link to your site.”
  • Actions: Connect website (primary alt) · Post without link (secondary) · Cancel
  • After “Post without link,” proceed social-native (copy + media, no site URL)
  • Light banner on Social settings / calendar when WP missing
  • No silent dead-link social shares for WP-less users
Screens to click
  • A — Blocked empty state · share dialog gated · calendar blocked
  • B — Compose without link · FB/LI/IG preview · optional “Add link later”
  • C — Banner · warn dialog · connect WP · post without link → social-native
Out of scope (this pass)
  • content-library / Meteor app code

  • Real OAuth / publish / PII

Directions

ALT

A — Gate until WP connected

Block social share/schedule until WordPress is connected. Clear empty state + Connect website CTA. Fights independent-channel model.

 ALT

B — Social-native (no site link)

Allow share with copy + media only. No site URL required (optional Add link later). Zero friction; no warn.

 RECOMMEND

C — Hybrid warn + post without link

Allow social when WP missing, but warn before post. Connect website · Post without link · Cancel. Banner when WP missing.

Build contract (provisional · recommend C)

Recommend C: warn before post when WP missing; never silent dead links. Full AC: build-contract.html. Soft Dev hold until Alex locks.
