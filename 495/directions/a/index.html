Direction A · recommended

Under every AI answer: Use this for: Website · Social · Email. Pick one or more, review everything in one sheet, then Create drafts once.

  • One review place, one button, no retyping.
  • Default is drafts. Nothing goes live or sends from the chat.
  • Replaces today's playground “Where should this go?” → Confirm Send chat steps, which publish for real.

This screen

The action bar shows on any answer that has a draft. “Review drafts” stays disabled until something is picked. The Shorter / Friendlier chips still work, and the action bar always uses the latest version.

Picking

All three picked. The button counts them. Destinations the account doesn't have (e.g. no Email Campaigns) don't show at all.

Review sheet

Each tab is prefilled. Purple tags = AI changed it for this destination. Blue tags = copied straight from the chat. Green dot = ready, amber = needs something.

Try the tabs, the social character counts, and “What changed?”.

Success

One message with a link to each draft. A strip at the top remembers the drafts from this chat, so a follow-up like “make LinkedIn friendlier” updates that draft instead of making a new one.

Not set up

No social account and no email list. The sheet opens on the first tab that needs attention. Website still works, email saves without a list, and social is skipped with a Connect button. Nothing is a dead end.

Partial result

What was made, what was skipped, and the one step to fix each skipped one.

Error

One destination failed. The others are kept. Try again only retries the failed one, so there are no duplicates.

Phone

Same flow. Chips wrap, the review is a bottom sheet, and the create button is full width.

Typing works too

The chips/buttons are a visible fallback. Advisors can also just type “schedule the post” or “put this on my site”. The AI works out the destinations and date and shows a confirm card first. See the “Typed request” tabs.

Typed request

The advisor never has to know a trigger word. After any answer with a draft, the AI reads the message and decides: is this a request to create / schedule / send, a rewrite, or a question?

Here it found two destinations (LinkedIn, Email) and a date (“Tuesday morning”). It shows a confirm card. Nothing is created until Confirm. Change opens the normal review for edits.

Other phrasings that land here: “schedule the post”, “put this on my site”, “email this to my clients”, “post it to LinkedIn Tuesday”, “make this a newsletter”.

Not sure where

The AI is confident this is a “use it” request but not where. It asks one short question with the destinations as chips. If it's unsure whether it's a request at all, it asks “Want me to set this up, or change the wording?”

Rewrite

“Add my booking link” is about the wording, so the AI just rewrites. No confirm card. The fallback chips/buttons stay under the new version.
