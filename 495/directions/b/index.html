Direction B · least build

Three buttons under the answer. Each opens the page you already know, filled in with the chat text. One destination at a time.

  • No new review screen. Reuses Share (#168), the social composer and Create campaign.
  • Text is copied as-is; shortening is up to the advisor (Help me write).
  • Three trips for three destinations. The chat remembers which are done.

This screen

Buttons only show for the sections on this account. Today the advisor would have to copy and paste into each page.

Website

Advisors don't have a separate post editor (the HTML post editor is staff-only), so “Create website post” opens the Share dialog with Website ticked, using a private post made from the chat.

Back in chat

The done button turns into “✓ … open”, and the AI offers the next one.

Social

Full chat text in one box for every network. Long for social: the advisor shortens it with Help me write or by hand.

Email

Create campaign already accepts a starting subject, body and list, so this is mostly wiring. Body is the full article (no link to a live website post yet).

Typing works too

The chips/buttons are a visible fallback. Advisors can also just type “schedule the post” or “put this on my site”. The AI works out the destinations and date and shows a confirm card first. See the “Typed request” tabs.

Typed request

The advisor never has to know a trigger word. After any answer with a draft, the AI reads the message and decides: is this a request to create / schedule / send, a rewrite, or a question?

Here it found two destinations (LinkedIn, Email) and a date (“Tuesday morning”). It shows a confirm card. Nothing is created until Confirm. Open in editor opens the normal review for edits.

Other phrasings that land here: “schedule the post”, “put this on my site”, “email this to my clients”, “post it to LinkedIn Tuesday”, “make this a newsletter”.

Not sure where

The AI is confident this is a “use it” request but not where. It asks one short question with the destinations as chips. If it's unsure whether it's a request at all, it asks “Want me to set this up, or change the wording?”

Rewrite

“Add my booking link” is about the wording, so the AI just rewrites. No confirm card. The fallback chips/buttons stay under the new version.
