Build contract · Infographic builder (in-house)

Markdown: build-contract.md · Hub: index.html · Mock: Direction A

One-liner

Let advisors create branded infographics inside FC from HTML/SVG templates, apply the brand kit (logo, colours, fonts, contact footer), rasterize to PNG, save to the library, and insert into email — Canva optional for one-offs only.

Recommended UI (Direction A)

  • Library entry — Create → Infographic (or Infographics tab).
  • Pick template — Stat card · Tips list · Quote/insight.
  • Fill content — Editable headline / stats / tips.
  • Brand kit — Colours, font, logo, contact; live preview.
  • Export — Save to library · Insert into email · optional Download PNG.
  • Missing brand — Empty state → Settings & Branding.

Acceptance criteria (provisional)

  • ☐ AC-1: Start Create Infographic from library without leaving FC.
  • ☐ AC-2: ≥3 FC-native templates render as branded assets.
  • ☐ AC-3: Content fields editable; educational / non-advice sample copy.
  • ☐ AC-4: Brand kit updates live preview.
  • ☐ AC-5: Save PNG to library + Insert into email.
  • ☐ AC-6: Empty state when logo/colours missing.
  • ☐ AC-7: Canva/upload remains optional escape hatch.

In scope

  • Template-driven HTML/SVG → PNG inside FC
  • Brand kit apply (reuse logo/contact; new colours/fonts)
  • Save to library + Insert into email
  • Missing-brand empty state
  • Canva upload as escape hatch only

Out of scope / non-goals

  • Full Canva competitor / freeform design canvas in v1
  • White-label of the whole FC app
  • Recolouring finished JPEG uploads as the primary path

Open product questions

  1. Brand colours/fonts: new Settings fields vs only in builder?
  2. Who authors templates — FC admin only?
  3. Square vs story vs email widths?
  4. Does generated PNG go through compliance approval like posts?

Alternatives (not recommended)

  • B — Canva-first + stamp: No real colour/font theming.
  • C — External FC Studio: Extra login; API brand sync friction.
