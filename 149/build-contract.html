## Screens / flow (Direction B modal)

| Step | UI | Purpose |
|------|-----|---------|
| Backdrop | Dimmed Email Campaigns page | Context preserved |
| 1 · Audiences | Multi-select fake audiences with counts | Pick what to pull |
| 2 · Confirm | Target list radio (new named after audience **default** / existing); conflict note | **FTT Mail wins** — won’t re-subscribe local unsubs |
| 3 · Progress | Progress bar | Fake import |
| 4 · Summary | Imported / skipped / errors; dismiss → Lists chip refresh | Completion |
| Error | Invalid Mailchimp key | Reconnect CTA in modal **or** full-page banner |

Smoke path: **Import → pick audience → confirm → progress → summary** (Lists count chip bumps).

## Defaults for open questions (unchanged)

1. **Re-import:** One-shot primary; optional “Refresh from Mailchimp” on list later (secondary).
2. **Conflicts:** **FTT Mail wins** — never silently re-subscribe a local unsubscribe/bounce; show skipped count.
3. **Who:** Advisor self-serve where Mailchimp is connected; admin can act on behalf.
4. **Target list:** Default **new FTT Mail list named after the Mailchimp audience**; alternate: add to existing list (radio).

## States

- Connected (happy path) — chip green; modal enabled
- Disconnected / invalid key — banner + modal reconnect; demo via “Simulate bad key” or `?error=1`
- Empty audience selection — block Continue on step 1
- Importing — progress; Back/Next disabled
- Complete — summary; sessionStorage list bump; switch to Lists
