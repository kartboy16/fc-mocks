#599 Weekly picks review for managed advisors

Review screens for the rotation engine. Every Monday it drafts a slate of post picks for each managed advisor, with topic rotation built in. An admin approves, swaps or skips each pick. Designer-first mock with generic sample data. Not agent-ready. Soft Dev UI hold until Alex picks.

Rules shown on every screen: nothing is scheduled until it's approved · drafts never publish on their own · slates are built every Monday at 5:00 AM PT (profiles re-sync at 2:00 AM PT) · posts that need an update are skipped.

Recommend A, the table queue with a slate page and a swap drawer. It looks and works like Manage Advisor Posts, which admins already use. It handles 100+ advisors with filters and bulk actions best, and it's the smallest build (about 2.5–3.5 UI dev days).

Directions

  • A. Table queue → slate page → swap drawer (recommended): a full-width table with clickable status counters and bulk actions. Each advisor opens a full slate page with Prev/Next. Swap slides in from the right. About 2.5–3.5 days.
  • B. Split view → swap pop-up: the advisor list stays on the left and the slate opens on the right, with a week summary when nothing is selected. Swap is a centred pop-up. About 3.5–4.5 days.
  • C. Focus review, one advisor at a time: an overview with a progress bar, then step through advisors with "Approve all and next" and keyboard keys. Swap opens inline under the post. About 3.5–4 days.

Each direction has the three screens (1 Queue, 2 Slate, 3 Swap), which you can click through or jump to from the top bar, and a "Try a state" bar: Default, Loading, Empty, Error, Needs update and All approved.
