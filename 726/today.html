#726 Today

  • No onboarding flow yet. Contacts are added from Email › Lists.
  • CSV import (CSVImportModal.jsx, ContactCsvColumnMapping.jsx, utils/contactCsvImport.js): maps Email, First name, Last name and Tags by header aliases, with presets for Mailchimp, Outlook and Google Contacts CSV exports. No XLSX or vCard.
  • Mailchimp import (MailchimpImportModal.jsx): paste an API key, pick an audience, import with progress.
  • Unsubscribed contacts are already skipped on import (ses_unsubscribe_guard.js, #388).
  • No consent fields on contacts (ses_contacts.js).
  • Own sending domain (Email › Settings, SESSettings.jsx): a manual 4-step wizard. Enter the domain, copy TXT + 3 DKIM CNAMEs + SPF into DNS, check, set the sender. Unverified domains fall back to the platform default (utils/sesFromEmail.js). Reply-To is the From address.
  • Compliance email is set separately in Email › Settings (compliance mode, officer name, email).
